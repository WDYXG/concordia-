# Changelog

## 1.0.0 - 2026-08-12

First public research-prototype release.

- Added a reusable Riverbend world with five synthetic agents and six locations.
- Added multi-round observation, memory, action, validation, feedback, and voting.
- Added deterministic Game Master rules, skills, permissions, and a ballot ledger.
- Added four election conditions with seeded event schedules and order balancing.
- Added DeepSeek API integration with explicit live-run confirmation and token logs.
- Added hash and optional FastEmbed semantic-memory backends.
- Added a standalone browser visualization that can import local experiment JSON.
- Added offline tests and scripted demonstration data.
